### [🔬 Advanced RAG System](https://github.com/avyakt06jain/advanced-RAG-system)
Production RAG pipeline for insurance policy analysis — built for HackRX 6.0

- Hybrid retrieval using BM25 + FAISS semantic search with Reciprocal Rank Fusion
- Cross-encoder re-ranking with `ms-marco-MiniLM-L-6-v2`
- Grounded generation through Gemini 2.0 Flash with source citations
- Structural PDF chunking with header/footer suppression

`Python` `FAISS` `FastAPI` `PyMuPDF` `HuggingFace` `Docker`

### [⚙️ Distributed ML Scheduler](https://github.com/avyakt06jain/distributed-ml-scheduler)
Discrete-event simulation of ML job scheduling across heterogeneous compute workers

- Three scheduling policies: Round Robin, Least Loaded, Resource Aware
- Min-heap DES engine with full cluster simulation in milliseconds
- Parallel worker capacity modeling with lazy CPU slot draining
- Automated metric export and matplotlib visualizations

`Python` `DES` `Scheduling Theory` `matplotlib`
